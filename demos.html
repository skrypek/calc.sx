How to use

Three steps

01

Install CalcSX

If you haven't already, grab the macOS build from the Download section. Drag into /Applications.

02

Download a .calcsx demo

Pick any card above. Each file bundles the full session — coils, parameters, and every computed analysis layer already cached.

03

Open & explore

Double-click the file. CalcSX opens at the exact scene the session was saved from — no recomputation needed. Tweak a parameter, re-analyze, export ParaView bundles.
