Fusion 360 pipeline

From your bobbin CAD to analysis-ready layers in one export.

The CalcSX Fusion 360 add-in walks your bobbin's groove geometry, extracts winding-channel centerlines and surface normals, and writes a .bobsx file that CalcSX imports directly — preserving tape-stack orientation without PCA fallback.

Why a dedicated exporter

CAD geometry, without losing orientation

∇

Normals come with the coil

Every centerline point carries the groove-floor normal from the CAD model. CalcSX uses these directly for tape-stack orientation, skipping PCA fallback and its failure modes on non-planar coils.

⫸

Multi-groove, single file

A bobbin with N parallel winding channels exports to a single .bobsx containing all N coils — ordered, named, and ready for per-coil parameter overrides inside CalcSX.

⎔

Optional bobbin mesh

You can embed the bobbin solid itself — rendered as a translucent gray shell alongside the coils in the CalcSX viewport to give physical context during inspection.

Pipeline

How the export works

01

Select the bobbin body

Pick the multi-groove bobbin in Fusion 360's browser. The add-in enumerates every face and tags geometric features ready for chaining.

Screenshot
Fusion 360 viewport with a bobbin body highlighted. A CalcSX command dialog shows "Select Bobbin Body" with the picked feature name and bounding-box dimensions.
02

Auto-detect & chain grooves

Faces are classified as narrow (single-groove walls) or wide (multi-groove floors); a Union-Find pass merges segments across face boundaries into one continuous centerline per groove.

Diagram
Cross-section of a bobbin with three parallel grooves: narrow walls tinted one color, wide floors another. Merged centerlines render as three colored curves wrapping the bobbin silhouette.
03

Export .bobsx → open in CalcSX

Each groove is serialized with centerline points, per-point surface normals, and (optionally) the bobbin mesh. Open the file in CalcSX — coils appear in the browser with normals pre-populated, ready for analysis.

Screenshot
CalcSX main window after .bobsx import. Browser lists three coils; the 3D viewport shows them as colored tubes with the translucent gray bobbin mesh behind them.
.bobsx format

What's inside the file

▤

Centerlines

One ordered list of (x, y, z) points per coil. Closed by convention — no need to duplicate the start point at the end.

↗

Surface normals

Per-point unit vector pointing out of the groove floor. Used by _build_filament_grid to orient the tape stack consistently along the coil.

⎔

Bobbin mesh (optional)

Triangulated shell of the bobbin solid itself, displayed as a translucent gray layer in the viewport. Toggle visibility independently from the coils.

Install

  1. Download and unzip calcsx_exporter.zip.
  2. Move the unzipped calcsx_exporter folder into Fusion's add-ins directory: 
    # macOS
~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/

# Windows
%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\
  3. In Fusion: Utilities → Scripts and Add-Ins → Add-Ins → CalcSX Exporter → Run.
  4. A CalcSX panel appears in the ribbon. Pick your bobbin body → Export .bobsx.
