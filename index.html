Core capabilities

What CalcSX computes

◎

B-field analysis

Vectorized Biot-Savart kernel with volumetric current via Gauss-Legendre sub-filament discretization of the REBCO winding pack. On-axis and centroid sampling, plus 2D |B| cross-section heatmaps sliced along the symmetry axis.

↗

Lorentz force density

Per-vertex J×B color gradients rendered across tape-stack meshes. Every coil sees force contributions from every other coil via full multi-coil superposition.

◔

Hoop stress

Membrane-decomposition hoop stress (MPa) evaluated at each segment midpoint, rendered as a point cloud for rapid inspection of critical regions.

⤳

3D field lines

Magnetic streamlines via RK4 integration with conductor exclusion. Toggle between per-coil topology and a globally merged set across the whole environment.

⊞

Parametric coil generators

Solenoid, Princeton Dee, Saddle, and CCT generators with live preview — iterate on geometry without touching a CSV. Drop straight into the multi-coil environment.

L

Inductance

Self and mutual inductance via Neumann double-line integration over the discretized filament grid, with flux-linkage cross-checks against the Biot-Savart solution. Full n×n matrix for any multi-coil environment.

Workflow

CSV in, diagnostics out

01

Load geometry

CSV with parametrized coil, a .bobsx file exported from Fusion 360, or a .calcsx containing a full environment.

02

Set parameters & analyze

Configure winds, current, tape dimensions in the Properties panel. Run an analysis to rapidly calculate B-field, force, and stress layers.

03

Inspect results

Toggle 3D field lines, cross-section heatmaps, and layer visibility. Vary your design, prototype new coils, and re-analyze live in the app.

  1. Double-click the downloaded .dmg.
  2. Drag CalcSX.app into /Applications.
  3. First launch: right-click the app in /Applications → Open → confirm. Gatekeeper blocks a normal double-click because this build is ad-hoc signed.

    xattr -dr com.apple.quarantine /Applications/CalcSX.app
